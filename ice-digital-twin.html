The Physical Environment

The ICE Laboratory

The Industrial Computer Engineering (ICE) Lab at the University of Verona is a state-of-the-art demonstrator of Industry 4.0 and 5.0 technologies, created within the Italian Ministry-funded "Dipartimenti di Eccellenza" 2018-2022 project.

It serves simultaneously as a research infrastructure, a technology transfer hub, and the core teaching facility for the CEIS Master's degree in Computer Engineering for Intelligent Systems, attended by approximately 80 students from multiple countries each year.

Since 2018, the lab has supported over 100 technology transfer activities with regional manufacturing companies, resulting in more than 40 applied research projects and four university spinoff companies.

Official website: https://www.icelab.di.univr.it/

VR Digital Twin

The Virtual Reality replica

Running on Meta Quest 3, the VR application provides a fully navigable, real-time replica of the physical ICE Lab. Users move freely within the virtual space and observe machine states as they happen: transport lines running, mobile robots in motion, quality inspection in progress.

The VR twin communicates bidirectionally with the physical lab and the industrial digital twins, making it the ideal platform for remote learning without sacrificing fidelity.

  • 🌐

    Real-time synchronisation

    Machine states, production recipes, and robot positions are mirrored live between the physical lab and the virtual environment via MQTT.

  • 👋

    Gesture-based interaction

    The same gestural interface used in the AR app is replicated in VR, allowing users to control production recipes and inspect machines using hand gestures.

  • 🗺️

    Free spatial exploration

    Users navigate throughout the virtual lab, approaching any machine, reading operational data panels, and triggering machine actions.

  • 👥

    Collaborative sessions

    Multiple remote users can be present simultaneously, enabling team-based learning and teacher-guided tours of the virtual environment.

Intelligent Interaction

AI-powered virtual assistant

Every user in the virtual ICE Lab can query a context-aware AI assistant by voice, getting real-time, machine-specific answers about the equipment they are looking at.

The virtual assistant integrates three components: a local speech-to-text engine, a gaze-based context detector, and a cloud LLM. When a user activates the push-to-talk interface, their voice is transcribed by Whisper.ai running locally on the headset, ensuring accuracy with technical industrial vocabulary. The GazeDetector simultaneously identifies which machine the user is looking at via a 20-metre raycast, capturing both the machine ID and its current operational status.

This context bundle (transcribed question, machine ID, and live machine state) is sent to Google Gemini via a Google Apps Script bridge. Gemini returns a technically precise, context-specific answer, which is then synthesised to speech using Google Translate TTS and played back through the avatar. Total round-trip latency is approximately 8 seconds.

  • 🎤

    Push-to-talk, local transcription

    Whisper.ai processes audio locally (up to 10 seconds), filtering background noise before passing validated text to the cognitive layer. No cloud dependency for the transcription step.

  • 👁️

    Gaze-aware machine context

    The system identifies which machine the user is looking at and bundles its live operational status with every query; Gemini answers about the specific equipment, not the lab in general.

  • 🤝

    Personal AI and synchronised guide

    Each user's personal assistant answers privately. The synchronised guide assistant delivers the same narration and events to all participants simultaneously across the VIROO multiplayer session.

Whisper.ai: Speech to Text

Local inference on the headset. Handles technical industrial vocabulary more reliably than cloud STT in noisy lab environments, with no external dependency for the transcription step.

Google Gemini LLM

Selected after comparative testing against ChatGPT: Gemini demonstrated superior ability to interpret real-time machine operational status and ICE Lab domain knowledge, with better response speed for this context.

Latency mitigation

The current ~8-second response time is bridged by "thinking" animations and introductory phrases on the avatar. Future iterations will implement streaming responses to reduce perceived latency further.

AR Digital Twin

Augmented Reality on the physical machines

Running on Meta Quest 3 in AR/passthrough mode, the application superimposes digital overlays directly onto the real machinery in the ICE Lab. The colour video passthrough renders the physical environment inside the headset while virtual elements are spatially anchored to the actual equipment.

For the robotic trajectory planning scenario, manipulability ellipsoids and trajectory visualisations are rendered on top of the physical JAKA ZU 5 robot arm, enabling students to connect path planning theory directly to the hardware in front of them, without losing the real-world reference.

  • 📌

    Spatially anchored visualisations

    Ellipsoids, trajectory paths, and data overlays are locked to their physical counterparts in the lab and remain in place as the user moves around the machine.

  • 📈

    Live kinematics data overlay

    Real-time robot joint states and manipulability metrics are displayed as floating panels above the relevant equipment via the ROS/URDF backend.

  • 🤖

    Trajectory exploration

    Students interact with trajectory representations anchored to the physical arm, exploring how target pose and joint configuration affect workspace reach and singularity avoidance.

New in ICETeachXR

Collaborative educational content layer

ICETeachXR extends the existing digital twin with a purpose-built system for creating and sharing learning modules.

Teacher authoring tools

Professors create guided tasks, add annotations, and define step-by-step learning sequences directly within the virtual ICE Lab, both synchronously (live session) and asynchronously (pre-recorded module).

Cross-device availability

The same virtual environment is available on Meta Quest 3 standalone (immersive VR), VIROO desktop client (PC), and Meta Quest 3 in AR/passthrough mode, delivering a consistent learning experience regardless of hardware availability.

VIROO platform integration

The ICETeachXR platform is integrated with the VIROO package provided by MASTER-XR, ensuring compatibility with the wider ecosystem and enabling portability to other educational contexts.
